# BetterPPTX 1.10.55 / 2026-09-29.1

## Changes

- Named art-direction Worlds and light/dark requests are optional. Omission/null no longer applies an implicit Luxe/Editorial preset or blocks certification. AI-authored geometry, styles and motion remain authoritative; complete business ambition is advice, not an effect quota.
- The task creator is authorized to use only its configured worker identity. Release preflight checks that scoped permission. Dispatch errors retain an opaque operation recovery path instead of exposing private infrastructure details or incorrectly denying safe identical recovery.
- Cloud artifacts have an opaque browser download route. It resolves only a previously issued, owner-bound, generation- and hash-bound publication, preserves the exact signed storage URL, and tolerates only ChatGPT's documented URL decoration. Large presentations do not need to enter chat as embedded Base64.
- New links and retained files share their original 12-hour expiry. Retrieval/replay does not extend retention, regenerate the presentation, charge, or consume another publication.

## Evidence boundaries

Focused deterministic tests cover contract schemas, neutral and named styling, geometry, cloud link authority, cold recovery, expiry, ownership and provider dispatch failure. Deployment and supported ChatGPT-client results are recorded separately after observation. Local fixtures are not public-client delivery evidence; no appearance or playback qualification is implied.

The attached 1.10.54 acceptance report remains a bounded regression: its commit failed before publication and used/reserved stayed zero. Its old connector schema differs from the raw server schema. A normal ChatGPT tool refresh is required to recheck that projection; the server cannot guarantee host cache refresh.

Two legacy World integration scripts still target the old developer checkout and request obsolete engine-owned semantic geometry. They fail authoring-contract validation and are not current release qualification; the new exact-authoring tests exercise named Worlds without restoring that route.
