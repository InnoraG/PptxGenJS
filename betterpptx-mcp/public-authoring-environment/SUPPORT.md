# Support

Use the structured public response before escalating:

- Tool unavailable: confirm the BetterPPTX connector is installed and enabled.
- Authentication required: follow the public authentication instruction; do
  not paste credentials into this repository.
- Upgrade required: explain the blocked capability and ask the user whether to
  activate access or choose a truthful alternative.
- Invalid spec: use public capability help, workflow guidance, and the exact
  schema finding to correct the semantic request.
- Preview or validation failure: keep the deck unsaved, correct the candidate,
  and repeat the pre-release gates.
- Teaching drift: report the public tool name, sanitized error code, teaching
  release manifest digest, and expected public behavior. Do not request private
  logs or internal diagnostics.

For account, billing, privacy, or security matters, use the private support
channel on the product's official distribution page.
