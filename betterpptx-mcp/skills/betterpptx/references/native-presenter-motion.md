# Native presenter motion authoring

Presenter motion is authored semantically. The AI chooses exact `motion.*` IDs from `betterpptx.authoring.catalog`; the engine validates the selection, builds a native editable presenter bundle, and never silently substitutes another clip.

Use `motionTime.kineticSelection.presenters[]` to declare one ordered `selectedMotionIds` list per presenter. A PowerPoint presenter bundle is limited to 18 clips, while the public catalog may contain more rows. `slides[].presenterMotion` selects one ID from that presenter’s bundle and may bind it to a narration phrase or explicit millisecond cue. Narration remains the master clock when narration is present.

For cast beats, set `slides[].scene[].loop` to `false` to play the selected motion once and hold its final pose until slide advance. For example, `scene: [{ actor: "host", motionId: "motion.ordinary.talk", at: 800, loop: false }]` starts that motion 800 ms after the slide begins. `true` or omission retains repeating playback. This option does not reverse, shorten, or accelerate the motion, and does not change its stopped/edit posture. Allow the start delay plus the catalog motion duration and any desired final hold before advancing. `showSettings.loop` controls repetition of the whole slideshow, not individual presenter motions.

The catalog exposes semantic family, purpose, interaction verbs, loopability, energy, tempo, and availability. Selectable rows are backed by native playback evidence; planned or playback-held rows remain visible only in the planned catalog view and fail closed if requested. Interaction-specific reach, press, carry, travel, and contact motions require their own measured native source; do not approximate them with an unrelated gesture.

Presenter identity, model choice, stage treatment, camera, viewport, scale, rotation, lighting, and motion timing are separate typed controls. Omit a field to retain the selected default. Set a named field or the complete presenter-motion component to `null` to reset, then dry-run and re-edit from the returned semantic readback. Private animation slots, clip maps, source paths, and bundle handles never belong in a public JSON spec.

For release proof, use a fresh public session to discover the catalog, upload a semantic JSON spec, run a mutation-free dry run, commit, validate quality, preview, save, reopen the saved package, and inspect native package/Office roundtrip evidence. Production-non-rendering delivery still runs the applicable deterministic package, selector, timing, and accessibility checks without hosted PowerPoint; it must record that no render was performed. Motion timing and captions are different surfaces: narration cues synchronize a presenter beat; visible slide captions are not generated, while native WebVTT captions belong to an explicitly authored media track.
