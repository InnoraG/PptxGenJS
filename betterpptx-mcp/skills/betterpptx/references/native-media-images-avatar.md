# Native media, image, and avatar authoring

This catalog family is broader than one formatting contract. Discover the relevant surface before writing a spec: `pictureStylePreset` exposes 28 editable Picture Style families plus typed line/3-D controls; `imageAdjustments` exposes corrections, recolor, duotone, and artistic-effect leaves; `imageFraming` exposes the exact `contain | cover | crop` selector; `imageAccessibility` carries alt text; and `mediaPlayback` exposes audio/video/online type, package-safe extension identity, sizing, volume, caption tracks, and stopped-state behavior. Narration, media timing commands, sample assets, validation oracles, and imported-picture/media preservation are separate owner contracts and must not inherit Picture Format fields.

Presets are starting treatments. Omitted structured fields inherit the selected preset; authored fields override only their named components. Set `pictureStyle`, `pictureStyle.geometry`, `pictureStyle.line`, `pictureStyle.effects`, `pictureStyle.threeD`, or media/image components to `null` for deterministic component or full reset. Keep native media and picture objects editable; never flatten a source into a screenshot to hide a missing control.

Use public asset handles, HTTPS links, or inline data; never send or expose private filesystem paths. Media `extn` must match the selected audio/video type and the detected payload bytes. Media commands are limited to native `playFrom(nonnegativeSeconds)`, `togglePause`, and `stop`; set the owned command field to `null` to remove generated commands without deleting unrelated imported timing. Native WebVTT tracks are media-owned parts and must be added, replaced, or removed together with their relationships.

For framing, author an exact object frame under the active geometry route and choose `sizing: { type: "contain" | "cover" | "crop" }` for content within it. Set `sizing: null` to restore native stretch framing while retaining the asset. Imported `cNvPicPr`, `blipFill`, crop metadata, bookmarks, picture/media relationships, and unedited line/effect/timing payloads are preserve-only evidence, not public raw authoring fields. Bundled sample assets are not implied by format support. State structured-partial boundaries explicitly for provider-backed TTS, voice-artifact lifecycle, generic operation rollups, hyperlinks, and bookmark/trigger semantics until their own contracts close. Production-non-rendering delivery binds the package to deterministic package/media/timing/accessibility/selection evidence. PowerPoint reopen, appearance, captions, and playback are separate release qualification, not mandatory hosted production gates.
