# Public cold-AI curriculum canaries — 2026-08-17

## Purpose

Test whether the development public authoring environment teaches ambitious presentation judgment—not merely BetterPPTX
tool syntax—without giving the client private implementation context.

Environment under test:

- public repository commit: `0626a80ada2b30c1f98cfb599c6a7f88820136e0`
- public manifest SHA-256: `aaab74404947e3231af9a7315af0f47f8c89967bdd371a23a2ddf8fbe45a9d93`
- canonical/public skill-tree SHA-256: `d6821ffeefadd63b7f96b270a7c43d97324281bddcbdeb4d288b7065eb1bf7f7`
- release state: `development`

## Boundary

Three fresh AI tasks were created with no parent-conversation history and were instructed to read only
`release/betterpptx-public`. Each produced a zero-save authoring plan and attested that it used no private source,
maintainer diagnostics, prior task material, local engine route, authored geometry, or package workaround. No MCP
authoring operation, provider call, or `deck.save` occurred.

This is an instruction-bounded, self-attested curriculum test. It is not an OS-enforced filesystem isolation proof,
not an executable public-MCP canary, and not first-time-right certification.

## Results

| Canary | Distinct authoring judgment elicited | Public-boundary result |
|---|---|---|
| General-audience protein-folding explainer | A six-slide “Molecular observatory” arc; toy search-space equation explicitly labeled illustrative; rugged energy-landscape mechanism; learned-constraint pipeline; native 3-D only with rights-cleared public assets; confidence separated from certainty; prediction closed by experiment. | PASS |
| City-council protected-bike-lane decision brief | A six-slide “Civic Evidence Ledger”; conditional rather than advocacy-first recommendation; measured/estimated/benchmark/unknown distinctions; ranges and denominators; options evidence matrix; preregistered guardrails; accessible/static public-trust treatment. | PASS |
| Robotics-conference motion/presenter keynote | A seven-slide “assured technical theatre” arc; native presenter used as a supplemental carrier; exactly two semantic gestures; narration as master clock; separate full/reduced/static candidates; no visible captions; zero talking-head route; static-complete meaning. | PASS |

All three clients independently refused to fabricate executable catalog IDs and instead planned focused public catalog
queries plus an AI-authored selection manifest. All three kept creative authority with the AI while assigning geometry,
package validity, factual validation, and deterministic execution to the engine.

## Judgment

The curriculum baseline is strong enough to proceed to executable fresh-client canaries. It materially changes the
client's reasoning across story architecture, medium selection, art direction, typography, data honesty, native-object
use, accessibility, motion, and release discipline. It does not yet prove that the installed/served skill matches these
bytes, that a client can execute the plans against the live black-box MCP, or that the first saved artifacts pass the
held-out visual and PowerPoint gates.

## Next gate

Install/serve the exact frozen skill tree in an isolated public-client profile, bind the installed bytes and public tool
schema fingerprints, and execute the goal's new-deck, bounded-revision, and narrated/native-3-D canaries with zero
candidate saves. Only after those pass may the environment become a release candidate for held-out first-save proof.
