# EasyPortrait commercial-lane notice

The commercial BiSeNet experiment uses the upstream [EasyPortrait](https://github.com/hukenovs/easyportrait) repository and its EasyPortrait v2 data/checkpoint artifacts. The upstream project publishes a variant of the Creative Commons Attribution-ShareAlike 4.0 International terms and asks downstream users to retain the accompanying attribution/share-alike notice.

This lane is separate from the resale-safe worker. Any checkpoint derived from EasyPortrait must retain the upstream license notice and must not be silently copied into the resale-safe model bundle. The owner-approved commercial deployment decision covers use of this lane subject to preserving those notices and any applicable attribution/share-alike obligations.
